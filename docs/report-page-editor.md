# 报表画布编辑器

在目标项目运行 `site sync` 后使用新版报表。左侧纸张用于编辑，右侧实时预览；窄屏上下排列。输入中的正文、Markdown、HTML 和图示会直接显示在预览中。

## 在画布上编排

- 第一页保留标题、副标题输入，右侧同步预览；第二页及后续页不重复显示页头标题、副标题。
- 编辑区与预览区的纸张分别居中，放大超出区域时可横向滚动。
- 点击“全屏编辑”隐藏应用头部，点击“退出全屏”或按 Esc 恢复。
- 使用缩放按钮或 Ctrl／⌘ + 鼠标滚轮缩放画布（25%–200%），点击百分比恢复 100%；缩放不影响 PDF。
- 每行前后提供“单列”“双列”“三列”“新页”按钮，在对应位置添加布局。
- “新页”创建另一张独立纸张，自动定位到新增区域；保存模板和 PDF 导出均保留分页。
- 每行工具条支持更改列数及左右宽窄比例、拖排、上移、下移、复制和删除。缩减列数不会删除内容，多出的区块保留为后续单列行。
- “撤销排版”恢复最近的结构操作。删除一页的首行时，其后续内容仍保留在该页。

## 区域内编辑文字

点击区域，选择“编辑文字”，在区域内切换纯文本、Markdown 或 HTML 并编辑。

- “保存内容”将文字应用到画布，恢复渲染。
- “取消”放弃本次文字修改，保留原内容。
- 其他区域始终保留已经应用的渲染结果。
- 编辑文字期间先保存或取消，再执行排版、预览、模板保存或导出，避免丢失未应用的修改。

Markdown 支持标题、列表、引用、代码块及 GFM 表格。HTML 支持常见正文标签、表格、链接和基本文字样式，不执行脚本、事件属性或嵌入页面。Markdown 中不执行原始 HTML，请使用 HTML 格式编辑 HTML 内容。

## 插入图表图片

1. 在目标区域点击“图表图片”，展开左侧图表筛选面板。
2. 选择模型、图表形式、字段、聚合方式和筛选条件，点击“生成报表”。
3. 点击面板底部的“插入 / 替换当前图表”，结果进入选中区域，左侧面板自动收起。

面板底部按钮与筛选滚动区分开布局，不覆盖选择区域。同一区域可同时有说明文字和图表。图表保存独立查询条件，可以来自不同模型。日期支持固定日期与近 7、30、90 天，动态日期在每次查询时重新计算。

这里的“图表图片”由报表筛选生成；外部图片可通过 Markdown 或 HTML 的 HTTP(S) 图片地址、站点根路径插入。

## 模板与 PDF

完成各区域编辑后，点击“保存模板”持久保存整份页面。“保存内容”只应用当前区域，不能代替保存模板。模板保存到数据库中的 `report_templates` 表，并按当前用户隔离；保存的是标题、正文、版式与查询配置，不保存查询结果。旧版浏览器 localStorage 模板会在首次打开且账号还没有数据库模板时自动迁移。打开模板或点击“刷新图表”会重新查询数据，后端权限继续生效。

可使用“导出 JSON”下载当前页面（格式为 `{ "version": 1, "report": ... }`），并用“从 JSON 导入”把同一格式的文件作为一个新模板保存到数据库。

“专注预览”隐藏画布上的编辑工具。“导出 PDF”打开浏览器打印窗口，选择“另存为 PDF”。输出保留各页正文、表格、图表和页尾，排除编辑控件及选中边框。显式新页保留分页；内容过长时浏览器也会自然分页。图表加载失败时禁用导出。

## Mermaid 图形

在区域工具条点击“Mermaid”，或在内容格式中选择 Mermaid，输入 Mermaid 源码后点击“保存内容”渲染。支持流程图、时序图等 Mermaid 图形，无需 Markdown 代码围栏。首次添加会提供流程图示例；已有文字会保留在编辑器中，可取消修改。

源码随报表模板保存，图形支持专注预览与 PDF 导出。渲染失败会显示语法错误，加载中或存在错误时会阻止 PDF 导出。现有项目运行 `site sync --install` 同步模板并安装新增依赖。
